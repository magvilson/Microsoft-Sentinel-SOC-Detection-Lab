# Lab Evidence

This directory contains screenshots and supporting evidence from the Microsoft Sentinel SOC Detection Lab.

The evidence demonstrates the end-to-end SOC workflow, including:

- Microsoft Entra ID sign-in log analysis
- KQL threat detection
- Microsoft Sentinel analytics rule configuration
- Alert and incident generation
- Incident investigation
- Entity and source IP analysis
- Alert/incident grouping
- Detection tuning
- Incident resolution and classification
- Microsoft Defender incident investigation
